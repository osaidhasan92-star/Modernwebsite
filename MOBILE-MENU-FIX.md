# Mobile Menu Fix

Updated the responsive navigation for phones and small tablets.

- Hamburger menu opens as a full-width panel below the header.
- Products opens/closes by tapping the Products row.
- Product submenu is single-column on mobile for readability.
- Dropdown is no longer hidden by the desktop hover rules.
- Menu has a viewport-height limit and scrolls when necessary.
- Logo and hamburger are sized to fit narrow screens.
- Tapping a normal navigation link closes the menu.
- Tapping outside the navigation closes the menu.
- Desktop hover dropdown behavior remains unchanged.
