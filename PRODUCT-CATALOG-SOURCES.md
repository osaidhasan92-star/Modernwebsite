# Product catalogue sources

This build contains all 170 product entries currently exposed by the public MKT catalogue (13 pages, 14 items per page except the final page). Product names were read from the live catalogue. Exact MKT image URLs are used where they were available in the supplied website mirror; category-specific reference images are used for products whose original media was not present in the supplied archive.

The supplied mirror is an HTTrack-style snapshot and does not contain every original product image.
